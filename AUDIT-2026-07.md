## 1. What's already excellent (don't touch)

- **At-most-once send dispatcher.** `dispatchDueScheduled` reserves and persists due
  messages *before* sending, so an overlapping cron tick can't double-text a customer.
- **KV write-budget discipline.** Idle threads skipped before load; index batched to one
  write per tick; no-op writes de-duped. The whole cron respects a hard ~1,000 writes/day.
- **The follow-up state machine.** Owed-reply → escalating nudges → won-review → rebook →
  lost-revival, with quiet hours, global + per-contact autopilot, and snooze.
- **Playbook-grounded AI.** One business "brain" feeds draft/polish/summary/triage/coach,
  with golden rules ("never confirm a price"). Consistent and safe.
- **Team mode & AI coach.** Assignment, per-reply attribution, and a coach that tells a new
  hire exactly what to say — onboarding baked into the inbox.
- **Spam defense & free alerts.** Press-1 call screening + block list; email alerts (Resend)
  already replace paying Twilio to text yourself.

---

## 2. Fix-first: security & trust

- **SEC-01 — CRITICAL — Webhooks accept anyone.** `/sms`, `/call`, `/voicemail`, `/submit`
  take any POST with no `X-Twilio-Signature` validation and no honeypot on the quote form.
  Spoofable → fake threads, real Twilio spend, KV pollution.
  **Fix:** validate the Twilio signature on every carrier webhook; add a honeypot field +
  per-IP rate limit on `/submit`. ~40 lines, no new deps.
- **SEC-02 — HIGH — No opt-out ledger, no delivery truth.** `sendSms` treats "accepted" as
  "delivered," so carrier-filtered replies die silently. No STOP ledger → scheduled sends and
  autopilot keep firing at opted-out numbers (A2P/TCPA exposure).
  **Fix:** pass `StatusCallback` on every send (record queued→sent→delivered/failed, show in
  the bubble); same webhook records STOP/START into a KV opt-out set that `sendSms` checks
  before every send; show a "Do not text" badge.
- **SEC-03 — MEDIUM — Login brute-forceable, session never rotates.** `/api/login` has no
  throttling; the cookie is a deterministic SHA-256 of the password — never rotates, 90-day
  life, unrevocable without changing the password.
  **Fix:** throttle failed logins in KV; issue a random server-side session token; add
  "sign out all devices."
- **SEC-04 — LOW — Loose CORS & open import route.** `Access-Control-Allow-Origin: *` on all
  API responses; `/api/migrate` fetches/imports from an arbitrary `?from=` URL.
  **Fix:** scope CORS to your origin for `/api/*`; allowlist or remove `/api/migrate`.

## 3. Scale & data model

- **SCALE-01 — Migrate to D1.** `threads-index` is read-modify-write on every message and
  action (drop-update race), and `/api/insights` re-reads every thread on each open
  (`O(everything)`). Moving threads/messages to **D1 (SQLite)** kills the race, makes Insights
  one indexed query, removes the writes/day tightrope, and unlocks real reporting. Highest-
  leverage refactor here.
- **SCALE-02 — Inbound photos discarded.** MMS becomes the string `[N attachment(s)]`; the
  `MediaUrl` values are dropped. For detailing, the customer's photo *is* the quote.
  **Fix:** store `MediaUrl0..N`, proxy into **R2** so links don't expire, render in-thread.

## 4. UI & UX: from clean to high-end

Strengths: swipe actions, haptics, adaptive polling backoff, bottom-sheet details, accent
picker. Gaps:

- **UX-01 — Dark-only.** No light theme, ignores `prefers-color-scheme`. Add a token-based
  light theme + manual override (accent picker keeps working in both).
- **UX-02 — Accessibility.** `user-scalable=no` blocks pinch-zoom (WCAG fail); no
  `:focus-visible` rings; faint-grey text below comfortable contrast. Add zoom, focus states,
  contrast bump, `aria-live` on toasts.
- **UX-03 — Search stops at the list.** No in-thread find or date jump; no operators. Add
  in-thread search + `status:` / `tag:` / `is:unread` operators.
- **UX-04 — No delivery state in bubbles.** Sent/queued/failed look identical. Add
  Sent · Delivered · Failed ticks + one-tap resend (pairs with SEC-02).
- **UX-05 — Text-only composer.** Can't send/view photos. Add attach (camera + library) via
  Twilio `MediaUrl`, render images inline.
- **UX-06 — The AI brain is hidden.** The Playbook's fact fields ship empty and live in a
  drawer. Add first-run setup + a "Playbook N% complete" nudge in Insights.
- **UX-07 — No keyboard shortcuts / command palette.** Add ⌘K, `j/k`, `e`, `⌘↵`.
- **UX-08 — Polling, no skeletons.** Add skeleton loaders, optimistic send bubbles, and Web
  Push (#2) to replace polling.

## 5. Feature roadmap (ranked by ROI vs effort)

1. **Missed-call instant text-back** — auto-text unanswered callers. `handleVoicemail` hook
   exists; ~10 lines. Still not built. Highest ROI.
2. **Real-time web push** — `sw.js` has no push handler; add Web Push (VAPID), kill polling.
3. **Two-way photo messaging** — quotes from photos, before/after sells jobs; Gemini is
   multimodal and can pre-assess condition.
4. **Booking page & appointment lifecycle** — auto confirm/remind/on-my-way, Google Calendar
   sync, public `/book` self-scheduling.
5. **Pay-by-text deposits** — Stripe/Square link from the quote; kills no-shows; feeds P&L.
6. **Broadcast campaigns to segments** — throttled, opt-out-aware blasts (needs SEC-02).
7. **Customer profiles & vehicle garage** — structured vehicle/address/history/LTV.
8. **Referral engine** — trackable "$20 off when a friend books" on top of the won-flow.
9. **Real reporting suite** — revenue vs spend, win rate by source, avg job value, funnel,
   trends, charts (needs #5 + SCALE-01).
10. **After-hours AI auto-responder** — playbook-bounded FAQ answering with human handoff;
    never confirms price/time.

## 6. Optimize existing features to 100%

- **AI:** stream drafts token-by-token; cache the playbook preamble; add source citations.
- **Follow-ups:** track nudge→reply conversion + recovered revenue; A/B nudge wording.
- **Templates:** merge variables (`{first_name}`, `{quote}`, `{appt_time}`).
- **Scheduling:** natural-language times ("tomorrow 9am") in the business timezone.
- **Insights:** sparklines + trend callouts instead of static snapshots.
- **Leads:** drag-and-drop pipeline with a value field (dollars, not counts).
- **Voicemail:** transcribe recordings into the thread (readable + AI-usable).
- **Reliability:** push notifications on send/nudge failures instead of a buried `error`.

## The $10k thesis

A $10,000 tool isn't one with more buttons — it's one a business can't operate without. The
gap between "handles the texting" and indispensable is three moves: **never lose a lead**
(missed-call text-back, push, opt-out truth), **turn every job into the next one** (booking,
deposits, rebook, referral), and **show the owner the money** (real reporting on D1). The
foundation — send dispatcher, follow-up engine, playbook AI — is stronger than most paid
products. Fix the security flank, close the eight UX gaps, and ship the roadmap in order.
